# Phone Clock — 안 쓰는 안드로이드폰을 탁상시계 + PC 단축키 패드로

[PhoneBox](https://github.com/ersinkoc/phonebox)(MIT)의 구조를 참고했습니다. 폰은 **버튼 id만** 보내고, 실제로 실행할 내용은 **PC의 `config.json`에만** 있습니다.
PhoneBox는 전용 앱(APK)과 .NET 에이전트가 필요하지만, 이 프로젝트는 훨씬 가볍게 만들었습니다.

- **폰**: 앱을 설치하지 않고 크롬 브라우저만 사용합니다.
- **PC**: 파이썬 파일 하나(`server.py`)로 동작하며, 외부 패키지가 필요 없습니다.

```
[안드로이드폰 크롬]  ── USB(adb reverse) 또는 Wi-Fi ──▶  [PC: server.py]
  큰 시계 / 날짜                                         config.json 의 동작 실행
  단축키 버튼 ── POST /api/run/<id> ─────────────────▶  (키 입력, 프로그램 실행, URL 열기, 문구 입력)
```

## 파일 구성
| 파일 | 역할 |
|---|---|
| `server.py` | PC 서버. 폰에 화면을 제공하고 단축키를 실행합니다 |
| `config.json` | 버튼 목록, 시계 설정, 포트, Wi-Fi 토큰 (토큰 보호를 위해 git에 올리지 않음) |
| `config.example.json` | 설정 예제. `config.json`이 없으면 서버가 이 파일을 복사해 시작합니다 |
| `web/index.html` | 폰에 표시되는 시계와 단축키 화면 |
| `tools/extract_icons.ps1` | PC 아이콘을 PNG로 추출합니다 (서버가 자동 실행) |
| `start.bat` | 서버를 **창 없이** 백그라운드로 실행합니다 (이미 실행 중이면 재시작) |
| `stop.bat` | 서버를 종료합니다 |
| `start_console.bat` | 문제 확인용. 서버를 콘솔 창에 띄워 로그를 바로 봅니다 |
| `server.log` | 백그라운드 실행 시 기록 (접속 주소, 버튼 실행, 오류) |

## 1. PC 실행
- **자동 실행**: Windows에 로그인하면 시작프로그램의 `Phone Clock 서버` 바로가기가 서버를 **창 없이** 켭니다. 따로 실행할 필요가 없습니다.
- **수동 실행 / 재시작**: `start.bat`을 더블클릭합니다. 창은 뜨지 않습니다.
- **종료**: `stop.bat`을 더블클릭합니다.
- **Wi-Fi 접속 주소(토큰 포함)**: `server.log`에서 확인할 수 있습니다.
- **자동 실행 끄기**: `Win+R` → `shell:startup`을 열고 `Phone Clock 서버` 바로가기를 지웁니다.

파이썬 3.8 이상이 필요하며, 이 PC에는 3.12가 설치되어 있습니다.

> 처음 실행하면 Windows 방화벽 허용 창이 뜰 수 있습니다. Wi-Fi로 연결하려면 **개인 네트워크**를 허용하세요.

## 2. 폰 연결 — 둘 중 하나

### A. USB 연결 (권장: 안정적이고 충전도 함께 됨)
1. 폰에서 **설정 → 휴대전화 정보 → 빌드번호 7번 탭**으로 개발자 옵션을 켭니다.
2. **개발자 옵션 → USB 디버깅**을 켭니다. 같은 메뉴의 **충전 중 화면 켜짐 유지**도 켜 두면 좋습니다.
3. PC에 adb를 설치합니다. 아래 명령은 Google 공식 platform-tools를 설치합니다.
   ```powershell
   winget install Google.PlatformTools
   ```
4. 폰을 USB로 연결하고 디버깅 허용 창에서 "항상 허용"을 선택합니다.
5. 별도 작업은 필요 없습니다. 서버가 20초마다 USB로 연결된 폰을 확인해 `adb reverse`를 자동으로 설정합니다.
6. 폰 크롬에서 **http://localhost:8765**를 엽니다.

USB 연결은 폰 입장에서 localhost 접속이므로 토큰이 필요 없습니다. 또한 브라우저의 **화면 꺼짐 방지(Wake Lock)**가 동작합니다.

> 케이블을 뽑았다가 다시 꽂아도 20초 안에 자동으로 다시 연결됩니다.
> adb를 새로 설치했다면 `start.bat`을 한 번 실행해 서버를 재시작하세요.

### B. Wi-Fi 연결 (선 없이)
1. PC와 폰을 같은 공유기에 연결합니다.
2. PC 콘솔에 표시된 `http://<PC 네트워크 주소>:8765/?token=...` 주소를 폰 크롬에서 **한 번** 엽니다. 토큰은 폰에 저장됩니다.
   > 📝 `<PC 네트워크 주소>`에는 PC의 IP를 입력하세요. `server.log`에 전체 주소가 기록되며, PowerShell에서 `ipconfig`의 IPv4 주소로도 확인할 수 있습니다.
3. 화면 꺼짐 방지는 폰의 **개발자 옵션 → 충전 중 화면 켜짐 유지**로 설정하세요. 일반 http 주소에서는 브라우저 Wake Lock이 막혀 있습니다.

## 3. 탁상시계처럼 쓰기
**전체화면(주소창 숨김)**
- 화면을 아무 곳이나 **한 번 터치**하면 전체화면으로 바뀌고 가로 방향으로 잠깁니다. 브라우저 정책상 자동으로는 안 되고 터치가 한 번 필요합니다. 화면이 꺼졌다 켜져 전체화면이 풀렸을 때도 한 번 터치하면 됩니다.
- **앱처럼 항상 전체화면으로 열기 (선택)**
  - USB로 연결해 `http://localhost:8765`로 접속한다면: 크롬 메뉴 → **홈 화면에 추가(앱 설치)**를 누르세요. 아이콘으로 열면 처음부터 주소창 없이 전체화면입니다.
  - Wi-Fi 주소(`http://<PC 네트워크 주소>:8765`)로 접속한다면: 폰 크롬에서 `chrome://flags`를 열고 **Insecure origins treated as secure**에 `http://<PC 네트워크 주소>:8765`를 입력해 Enabled로 바꾸고 재시작하세요. 그 다음 홈 화면에 추가하면 앱처럼 설치되고, 화면 꺼짐 방지도 동작합니다.

**화면 구성 (벤토 그리드)**
- 시계, 날씨, CPU·RAM, 단축키 아이콘 8개가 각각 칸으로 나뉘어 있습니다.
- 화면은 **가로 모드로 고정**되어 있습니다. 폰을 세로로 세워도 화면 전체가 회전해서 가로 배치가 유지됩니다.
  - 왼쪽 위: 시계와 날씨
  - 왼쪽 아래: CPU·RAM 계기판
  - 오른쪽: 단축키 아이콘 8개
- 아이콘을 누르면 젤리처럼 튕기고 테두리에 네온 라이트가 켜집니다. 실행에 실패하면 테두리가 빨간색으로 빛납니다.
- 크롬 메뉴에서 **홈 화면에 추가**를 선택한 뒤 그 아이콘으로 열면 주소창 없이 전체화면으로 보입니다.
- **시계를 더블탭**하면 시계만 보이는 모드와 시계+버튼 모드가 전환됩니다. 선택한 모드는 기억됩니다.
- 화면 번인을 막기 위해 시계 위치가 1분마다 조금씩 이동합니다.
- 22시부터 7시까지는 화면이 자동으로 어두워집니다. `config.json`의 `night_dim_from`과 `night_dim_to`로 바꿀 수 있습니다.
- 좌측 하단의 점은 PC 연결 상태입니다. 초록이면 연결, 빨강이면 끊김입니다. 연결이 끊겨도 시계는 계속 동작합니다.

## 4. 날씨 · PC 성능 표시
시계 아래에 날씨와 이 PC의 CPU·RAM 사용률이 표시됩니다. `config.json`에서 설정합니다.

```json
"weather":  { "name": "대전", "lat": 36.3504, "lon": 127.3845, "refresh_min": 10 },
"pc_stats": { "enabled": true, "refresh_sec": 2 }
```
- **날씨**: PC가 [Open-Meteo](https://open-meteo.com)(무료, API 키 불필요)에서 받아 폰에 전달합니다. 폰에는 인터넷이 없어도 됩니다.
  - 표시 항목: 현재 기온, 날씨, 체감온도, 오늘 최고·최저 기온, 강수확률
  - 다른 지역으로 바꾸려면 `name`, `lat`(위도), `lon`(경도)를 수정하세요. 위도와 경도는 지도 앱에서 확인할 수 있습니다.
  - 표시하지 않으려면 `"weather"` 항목을 지우세요.
- **CPU·RAM**: 사용률이 60% 이상이면 막대가 주황, 85% 이상이면 빨강으로 바뀝니다. 표시하지 않으려면 `"enabled": false`로 설정하세요.

## 5. 단축키 버튼 편집 (`config.json`)
파일을 저장하면 **서버를 재시작하지 않아도** 15초 안에 폰에 반영됩니다.

```json
{ "id": "고유ID", "label": "버튼 이름", "icon": "이모지", "type": "...", ... }
```

| type | 필드 | 예시 | 설명 |
|---|---|---|---|
| `keys` | `keys` | `"ctrl+shift+esc"` | 단축키 입력. 공백으로 구분하면 순서대로 누릅니다. 예: `"ctrl+c alt+tab ctrl+v"` |
| `run` | `command`, (`cwd`) | `["C:\\Program Files\\...\\app.exe", "인자"]` | 프로그램 실행 |
| `open` | `target` | `"https://..."`, `"D:\\업무폴더"`, `"\\\\<네트워크 경로 입력>\\공유폴더"` | URL, 폴더, 파일, 네트워크 공유폴더를 기본 프로그램으로 엽니다 |

> 📝 네트워크 공유폴더는 `<네트워크 경로 입력>` 자리에 서버 주소(IP 또는 PC 이름)를 넣으세요. JSON 안에서는 `\`를 `\\`로 두 번 씁니다. 예: 탐색기 주소 `\\서버\공유` → `"\\\\서버\\공유"`
| `text` | `text` | `"감사합니다.\n담당자 드림"` | 지금 커서가 있는 창에 문구를 입력합니다. 한글도 됩니다 |

**버튼 아이콘**
- `run`과 `open` 버튼은 실행 파일, 폴더, 바로가기, 스토어 앱의 **실제 PC 아이콘**이 자동으로 표시됩니다. 서버가 시작될 때와 config.json이 바뀔 때 `web/icons/`에 PNG로 추출합니다. 추출에는 `tools/extract_icons.ps1`을 씁니다.
- 웹 주소(`https://...`)를 여는 버튼, `keys`·`text` 버튼은 `icon`의 이모지가 표시됩니다.
- 다른 프로그램의 아이콘을 쓰려면 `"icon_path": "C:\\...\\app.exe"`를 지정하세요. 단축키 버튼에도 쓸 수 있습니다.
- PC 아이콘 대신 이모지를 쓰려면 `"pc_icon": false`를 넣으세요.
- 아이콘을 다시 뽑으려면 `web/icons/`에서 해당 PNG를 지우고 서버를 재시작하세요.

**사용 가능한 키 이름**: `ctrl` `shift` `alt` `win`, `a`~`z`, `0`~`9`, `f1`~`f24`, `enter` `esc` `tab` `space` `backspace` `delete` `home` `end` `pageup` `pagedown` `left` `right` `up` `down` `printscreen` `hangul` `hanja`, `volume_mute` `volume_up` `volume_down` `media_play_pause` `media_next` `media_prev` `media_stop`, 기호 `; = , - . / [ ] \ ' \``

예시:
```json
{ "id": "teams_mute", "label": "팀즈 음소거", "icon": "🎙️", "type": "keys", "keys": "ctrl+shift+m" },
{ "id": "work",       "label": "업무폴더",   "icon": "📂", "type": "open", "target": "D:\\업무" },
{ "id": "taskmgr",    "label": "작업관리자", "icon": "📊", "type": "keys", "keys": "ctrl+shift+esc" }
```

## 보안
- 폰은 버튼 id만 보낼 수 있습니다. 임의의 명령은 실행할 수 없습니다.
- Wi-Fi 접속은 `token`이 맞아야만 동작합니다. 토큰은 처음 실행할 때 자동으로 만들어집니다. 토큰이 유출됐다면 `config.json`의 `token`을 `""`로 비우고 서버를 재시작하세요. 새 토큰이 만들어지고, 폰에서 새 주소로 한 번 다시 접속하면 됩니다.
- USB만 사용할 거라면 `"allow_wifi": false`로 설정하세요. 서버가 이 PC(127.0.0.1)에서만 접속을 받습니다.
- 관리자 권한으로 실행 중인 창(작업관리자 등)에는 키 입력이 전달되지 않습니다. Windows 보안 정책 때문이며, 필요하면 서버도 관리자 권한으로 실행하세요.
